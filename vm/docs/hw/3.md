# Домашнее задание 3

- Написать статический анализатор частот вхождений последовательностей из 1-2 параметризованных байткодов в программах на Lama
- Анализатор читает байткод из файла
- Расставляет метки переходов
  - Метка перехода разрывает последовательность байткодов
  - Для простоты предполагаем, что переходы внутрь байткодов встречаться не могут
- Считает вхождения последовательностей длиной не более 2 параметризованных байткодов
- Выводит их отсортированными по убыванию частоты, отбрасывая не встречавшиеся последовательности
- Анализатор проверяется на скомпилированных в байткод тестах производительности
  - Сейчас там единственный тест
